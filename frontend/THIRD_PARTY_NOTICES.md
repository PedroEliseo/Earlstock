# Third-party notices (frontend)

The built application ships `third-party-notices.txt` (served at `/third-party-notices.txt` and
linked from the footer). It is generated by `scripts/third-party-notices.mjs` before every `dev` and
`build` run, from the licence and notice files of all production dependencies, so it always matches
the installed packages.

## TradingView Lightweight Charts

Charts are drawn with [TradingView Lightweight Charts](https://www.tradingview.com/lightweight-charts/)
(`lightweight-charts`, Apache License 2.0). Its licence requires reproducing the attribution notice
from its NOTICE file and linking to <https://www.tradingview.com/> on the pages that use it.

- **Notice:** the upstream NOTICE file is not included in the npm package; a verbatim copy for the
  installed version is kept in [`licenses/lightweight-charts.NOTICE`](licenses/lightweight-charts.NOTICE)
  and included in the generated notices together with the full Apache License 2.0 text. When
  upgrading the library, refresh that copy from the matching release tag.
- **Link:** every chart panel shows a visible "Charts by TradingView Lightweight Charts" link to
  <https://www.tradingview.com/>. The library's own on-chart logo is disabled (`attributionLogo:
false`), which the licence allows when the link requirement is met otherwise: the logo is a
  focusable link inside the chart's `role="img"` container, which is not accessible.

The notice text reproduced verbatim:

```
TradingView Lightweight Charts™
Copyright (с) 2025 TradingView, Inc. https://www.tradingview.com/
```
